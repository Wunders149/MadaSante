1. Product Vision:
Mada Santé — “Manampy anao” — Ensemble pour une santé meilleure.
Mada Santé is a digital healthcare platform connecting patients with healthcare professionals and healthcare services.
The platform must allow a patient to:
- Find a general practitioner or specialist
- Request a medical consultation
- Choose consultation at a medical office, home, hospital, or clinic
- Find pharmacies and medications
- Request help finding unavailable medication
- Find laboratories and imaging centers
- Request laboratory/imaging services
- Contact hospitals and clinics
- Request emergency assistance and ambulance services
- Request a nurse at home
- Request medication delivery
- Pay through supported Malagasy payment methods
- Receive notifications and appointment reminders
Important: Mada Santé is not only a doctor-consultation application. It is a healthcare-services marketplace connecting patients with doctors, nurses, pharmacies, laboratories, imaging centers, hospitals, clinics, ambulance providers, and delivery personnel.

4. Consultation Booking
Allow patients to choose:
Consultation type
- Cabinet
- Domicile
- Hôpital
- Clinique
Flow:
Choose doctor → Choose consultation type → Choose date/time → Confirm → Payment → Appointment confirmed
Display a clear appointment summary.

5. Home Consultation
Patients can request:
“Un professionnel vient chez vous.”
Collect:
- Address
- GPS location
- Reason for consultation
- Preferred time
- Urgency level
- Additional information
Match the request with available professionals.

6. Pharmacy & Medication
Create a medication search system.
Patient enters:
“Paracétamol”
Display:
- Medication name
- Pharmacy
- Availability
- Distance
- Price if available
- Opening status
- Delivery availability
If unavailable:
“Médicament introuvable ? Nous pouvons vous orienter vers une autre pharmacie.”

Allow the patient to request:
“Trouver ce médicament”
The platform can contact available pharmacies.

7. Medication Delivery
Patient selects:
Pharmacy → Medication → Quantity → Delivery address → Delivery time
Statuses:
Demande créée → Pharmacie confirmée → Préparation → Livreur assigné → En livraison → Livré

10. Emergency & Ambulance
Create a highly visible emergency feature.
Button:
🚨 URGENCE
The patient can request:
“Besoin d'une ambulance”
Collect:
- Current location
- Patient name
- Phone number
- Emergency type
- Description
- Number of patients
Workflow:
Emergency request → Ambulance provider notified → Accepted → Ambulance dispatched → En route → Arrived → Mission completed
The interface should be extremely simple because the user may be under stress.

12. Payments
Support Malagasy payment methods:
💰 Payment methods
- Orange Money
- MVola / Mbola
Create a payment abstraction layer:
PaymentProvider
 ├── OrangeMoneyProvider
 └── MvolaProvider

Payment statuses:
- Pending
- Processing
- Successful
- Failed
- Refunded
Payments can include:
- Doctor fee
- Nurse fee
- Delivery fee
- Ambulance fee
- Platform fee
Clearly separate each component of the price.
Example:
Consultation        30,000 Ar
Delivery             5,000 Ar
Platform fee         2,000 Ar
----------------------------
Total                37,000 Ar
